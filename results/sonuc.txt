===========================================================================
 v7-FIXED ANAHTAR KONFIGURASYON
===========================================================================
  v7-fixed = EfficientNet-B4 + 2.5D Multi-View + LS-CE+Dice+Focal +
             Mixup + TTA + Yol A methodology fix

  Mimari   : DeepLabV3+ (smp) + EfficientNet-B4 ImageNet pretrained
  Girdi    : 2.5D = 3 komsu slice -> 3 kanal RGB-benzeri, 320x320
  Loss     : 0.4 LS-CE + 0.3 Dice + 0.3 Focal (gamma=2)
  Mixup    : alpha=0.2, p=0.5 per batch
  Optim    : AdamW lr=1e-4 wd=1e-3
  Sched    : CosineAnnealingWarmRestarts T_0=25 eta_min=1e-6
  Epoch    : 100 (84'te early stop, patience=25)
  Batch    : 6 (efektif 24, grad accum x4), AMP
  Sampler  : WeightedRandomSampler (S4 + S5 rare boost x10)

  Methodology Fix (Yol A):
    Train  : inline [0, 158) U [242, 401) + xline [0, 601)
    Val    : inline [160, 240) (orta blok)
    Buffer : +/-2 inline (2.5D komsu sizintisi engeli)
    Xline  : train_inline_mask ile val pikselleri image'dan cropped

  TTA      : original + HFlip + polarity inversion (~+0.5 puan)
  Eval     : 320x320 resized (original-resolution evaluator bekleyen is)

  Egitim suresi: ~5 saat (RTX 3060 Ti 8GB, AMP)
